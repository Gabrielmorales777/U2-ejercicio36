# U2-ejercicio36
### Proveedores de Identidad y Autenticación Externa (OAuth)

**Objetivo principal:** Desarrollar un sistema modular en Java que permita validar credenciales mediante diferentes proveedores de identidad externos.

Se implementa una clase abstracta `ProveedorIdentidad` y tres clases concretas (`AuthGoogle`, `AuthGitHub` y `AuthApple`), cada una con su propia lógica simulada de validación de tokens.

El ejercicio aplica **abstracción, herencia, polimorfismo y sobrescritura de métodos**, incorporando validaciones para rechazar tokens nulos o vacíos antes de realizar la autenticación.
